# tools/

Scripts to run by hand. RAM figures are approximate; `mem <script>` in game gives the exact cost. Figures follow the game's static RAM check (base 1.6GB plus each NS function named in the script and what it imports).

| Script | What it does | Flags | Requires | RAM |
| --- | --- | --- | --- | --- |
| [`status.js`](status.js) | One-screen summary of the whole run (incl. why the darknet manager isn't running). The BitNode block shows progress toward ending it per route (hacking: Daedalus invite augs/cash/level, The Red Pill rep, `w0r1d_d43m0n` level; Bladeburner: Black Ops done/total, rank, next Black Op and its chance), the route `node-eta.js` picked in full and the other on one line; `status.routeProgress: false` keeps only the hacking lines. Design: [`docs/bladeburner.md`](../docs/bladeburner.md#progress-toward-ending-the-bitnode) | none | SF4 (opt), SF5 (opt) | about 5.5GB |
| [`show-config.js`](show-config.js) | Prints the settings the scripts will use. Design: [`docs/config.md`](../docs/config.md) | `[section]`, `--example` | none | 1.6GB |
| [`set-config.js`](set-config.js) | Changes `data/config.json` for you: `route 4:3 2:1 5:1` (BitNode route; a bare `5` means one more level of 5 than you will own), `skip <script>`, `challenge bn1` (go for a challenge achievement, see [`docs/challenges.md`](../docs/challenges.md); `challenge clear` to stop), `set <path> <value>`, `unset <path>`. Keeps your other overrides, refuses bad JSON, checks the setting exists. Design: [`docs/config.md`](../docs/config.md) | `route`, `skip`, `challenge`, `set`, `unset` | none | about 2.6GB |
| [`reminders.js`](reminders.js) | Only without the Singularity API: startup.js runs it every minute and it tells you once each when a server worth backdooring can be (with the command to paste) and when you can afford TOR or programs. Design: [`docs/reminders.md`](../docs/reminders.md) | none | none | 5.55GB, for a moment |
| [`save-bitnode-mults.js`](save-bitnode-mults.js) | Run by startup.js once per run with BitNode 5 or Source-File 5: saves `data/bitnode-mults.json` for [`utils/bitnode-mults.js`](../utils/bitnode-mults.js). Design: [`docs/bitnode-mults.md`](../docs/bitnode-mults.md) | none | SF5 | about 6.35GB, for a moment |
| [`track-income.js`](track-income.js) | Logs income every 10 seconds | none | none | 2.7GB |
| [`debug-report.js`](debug-report.js) | Writes `data/debug-report.txt` to paste when something looks wrong: run, what is running (workers summed per script), why startup skipped things, the last pass of every one-shot, every port. Design: [`docs/debug-report.md`](../docs/debug-report.md) | `--full` (no length limits, every worker copy) | none | 5.5GB |
| [`dump-state.js`](dump-state.js) | Prints a snapshot of the game state to paste elsewhere | none | none | 8.55GB |
| [`list-backdoors.js`](list-backdoors.js) | Lists servers worth backdooring and the path to each | `--all` | none | 4.45GB |
| [`check-servers.js`](check-servers.js) | Lists purchased servers | none | none | 2.75GB |
| [`kill-all-remote.js`](kill-all-remote.js) | Kills every script on every server except home | none | none | 2.3GB |
| [`clean-home.js`](clean-home.js) | Removes files from home by folder prefix or all at once. Dry run unless `--yes`. Keeps itself; keeps `data/` unless `--include-data`, `.txt`/`.lit`/`.msg`/`.exe` files unless `--include-misc`, and `startup.js` (with `--all`) unless `--include-startup`. Try `clean-home /tools/exploits/` then add `--yes` | `<folder/ or file> ...`, `--all`, `--yes`, `--include-data`, `--include-misc`, `--include-startup` | none | 2.8GB |
